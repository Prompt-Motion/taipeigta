被通緝怎麼辦？

撞車、鬥毆、搶車都可能引來警察。實用做法不是硬碰硬：換小巷、拉開距離、離開小地圖上的搜索範圍，等通緝星等閃爍結束。機車鑽縫能力通常優於四輪車，逃脫時優先考慮機車。
